# Generated contracts

- Treat source annotations, schemas, and checked-in generated files according to the repository’s generation workflow.
- Regenerate API or reference output after changing its source; do not hand-edit generated output as the primary fix.
- Keep endpoint semantics in the REST/OpenAPI owning skills and link to them rather than duplicating the contract here.
- Review generated diffs for accidental routes, fields, examples, or sensitive data before publishing them.
