# Examples and READMEs

- Make examples copyable and runnable with the repository’s supported Go version and commands.
- Show the smallest successful path first, then document configuration, failure handling, cleanup, and operational limits.
- Keep environment variables, routes, payloads, and commands sourced from the implementation or checked-in configuration.
- Use safe redacted values in examples; never include credentials, tokens, or real personal data.
- Prefer one authoritative setup guide over duplicated instructions that drift.
